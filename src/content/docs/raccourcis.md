Les raccourcis de Coall reprennent ceux de Figma chaque fois que c'est possible. Sur Mac, **⌘** remplace **Ctrl**. La liste est aussi dans **Préférences**.

## Canvas et navigation

| Raccourci | Action |
|---|---|
| Espace + glisser, molette, bouton du milieu | Se déplacer dans le canvas |
| Maj + 1 | Tout afficher |
| Maj + 2 | Zoomer sur la sélection |
| Ctrl/⌘ + 0, Ctrl/⌘ + / − | Zoom à 100 %, zoomer, dézoomer |
| Ctrl/⌘ + F | Rechercher sur tout le canvas |
| Ctrl/⌘ + \ | Masquer ou afficher les panneaux |

## Outils

| Raccourci | Action |
|---|---|
| V, H, F, Maj + S, C | Outils : sélection, main, frame, section, commentaire |

## Sélection et disposition des frames

| Raccourci | Action |
|---|---|
| Maj ou Ctrl/⌘ + clic | Ajouter ou retirer une frame de la sélection |
| Ctrl/⌘ + A | Tout sélectionner |
| Ctrl/⌘ + Alt + G | Mettre la sélection dans une section |
| Alt + A · H · D · W · V · S | Aligner les frames sélectionnées |
| Alt + Maj + H · V | Répartir les frames |
| Ctrl/⌘ pendant un déplacement | Déplacer sans magnétisme |

## Édition

| Raccourci | Action |
|---|---|
| Double-clic dans une frame / Entrée | Entrer dans la frame pour éditer ses éléments |
| Échap | Sélectionner l'élément parent, puis sortir de la frame |
| Suppr / Retour arrière | Supprimer l'élément, ou archiver la frame |
| Ctrl/⌘ + D | Dupliquer l'élément ou la frame |
| Flèches (Maj = ×10) | Décaler l'élément ou déplacer la frame |
| Ctrl/⌘ + Z, Ctrl/⌘ + Maj + Z | Annuler, rétablir |
| Ctrl/⌘ + C, X, V | Copier, couper (archiver), coller |

## IA

| Raccourci | Action |
|---|---|
| / | Écrire une demande à l'IA |

## Appel

| Raccourci | Action |
|---|---|
| Ctrl/⌘ + E | Couper / rallumer la caméra (pendant l'appel) |

## Export

| Raccourci | Action |
|---|---|
| Ctrl/⌘ + Maj + E | Exporter |

## Mode Play

| Raccourci | Action |
|---|---|
| Échap (mode Play) | Quitter le prototype |

## Autres gestes utiles

- **Glisser sur le fond** avec l'outil Sélection : tracer un rectangle de sélection.
- **Double-clic sur un calque** (panneau Calques) : la vue zoome dessus.
- **Double-clic sur un texte** dans une frame : l'écrire directement. **Entrée** valide, **Échap** annule.
- **Double-clic sur le nom** d'une frame ou le titre d'une section : le renommer.
- **↑ / ↓** dans un champ numérique du panneau Design : ajuster la valeur (Maj : ×10).
- **↑ / ↓** dans la recherche (Ctrl/⌘ + F) : parcourir les résultats ; **Entrée** pour y aller ; **Échap** pour fermer.
- **Échap** quand vous suivez quelqu'un : arrêter de le suivre.
